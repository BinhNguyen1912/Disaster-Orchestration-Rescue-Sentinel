# Changelog: Cloudflare R2 Upload Integration

## Date: 2026-06-12

### Added
- Installed S3 client `@aws-sdk/client-s3`, `multer` and `@types/multer` dependencies.
- Created `StorageService` at `src/infrastructure/storage/storage.service.ts` wrapping AWS S3 client configured with Cloudflare R2 endpoint, access keys, and public access URL format.
- Created `StorageModule` at `src/infrastructure/storage/storage.module.ts` exporting `StorageService`.
- Created `UploadController` at `src/modules/upload/presentation/controllers/upload.controller.ts` providing REST endpoints:
  - `POST /api/v1/upload/single` - multipart single file upload.
  - `POST /api/v1/upload/multiple` - multipart multi-file upload.
- Implemented file filter validation (`BR-UPLOAD-01` only images and PDFs) and size constraint (`BR-UPLOAD-02` 10MB file limit) on the routes.
- Created `upload.helper.ts` at `src/shared/common/decorators/upload.helper.ts` to separate and encapsulate Multer validation logic (fileFilter and size limits) out of the controller.
- Registered `UploadModule` in `AppModule` and confirmed compilation runs successfully.
